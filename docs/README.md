## Layout

- `docs/guide/`: installation, operations, and channel configuration
- `docs/architecture/`: repository-only architecture decisions and system boundaries
- `docs/design/`: repository-only implementation-facing design notes
- `~/.crewline/crewline.json`: user config
- `~/.crewline/system.json`: optional system config
- `.omx/`: internal planning, runtime state, and working notes
